# Audio del preloader

Para activar el tango suave del preloader, colocar acá un archivo con este nombre exacto:

`por-una-cabeza.mp3`

Notas:
- Usar un archivo propio o con derechos de uso claros para web.
- Los navegadores bloquean autoplay con sonido; por eso el preloader muestra el botón “Activar tango”.
- El volumen se reproduce bajo y se desvanece al terminar el preloader.
